# مؤسسة أر الرقمي للتسويق الإلكتروني

موقع Landing Page عربي RTL، صفحة واحدة، مبني باستخدام HTML وCSS فقط.

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## GitHub Pages
ارفع الملفات إلى مستودع GitHub، ثم من:
Settings → Pages → Deploy from a branch → main → /root

ملاحظة: عدّل البريد `info@example.com` داخل `index.html` إلى بريد المؤسسة قبل النشر.
